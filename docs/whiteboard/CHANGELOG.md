# 在线画板 CHANGELOG

本日志只记录在线画板子项目。根项目发布历史仍写入仓库根 `CHANGELOG.md`。

## 1.0.2 - 2026-08-01

- 将公共画板和全部密码房显式锁定为同一套暖纸、石墨、hachure、高 roughness 铅笔草图默认值，不新增第二套房型主题。
- 可见页面改用每 60 秒一次的 WebSocket 静态 `ping/pong`；回复由 Durable Object auto-response 完成，不唤醒已休眠实例。隐藏标签页 60 秒后先排空未确认更新再停放连接，重新可见时自动差异同步。
- 客户端文档批处理调整为 250／500／1000ms，游标调整为 100ms；画布无变化时不发送 Yjs 持久化更新，连续活动时 D1 房间摘要最多约每分钟同步一次。
- 有连接房间的异常连接巡检从每 15 秒改为每 5 分钟，并使用最近 auto-response 判断 7 分钟失联；空公共房不再维持周期生命周期 Alarm，密码房仍只在最后离开后保留 24 小时删除计划。
- 普通连接波动不再弹出画布中央通用错误；不足 3 秒的恢复保持无提示，持续波动只显示角落小状态，权限、协议、容量和文件错误仍明确显示。

## 1.0.1 - 2026-08-01

- 修复快速绘制超过 Worker 每秒更新阈值后被 `1008 / rate_limited` 断开、未确认 Yjs 更新不再补传而导致线条退出后消失的问题。
- 客户端现在合并连续更新、按文档规模采用 Worker 建议间隔、一次只发送一个待确认批次；Worker 落盘后返回 `update-accepted`，断线或 ACK 丢失会把原批次安全重入队。
- 退出按钮会短暂等待待确认更新排空；限速关闭改为可恢复重连，并保留具体三语错误类型。
- 新增公共房跨断线/DO 唤醒永久保留回归，继续锁定密码房最后离开后 24 小时整房删除与重入取消删除。
- 默认新建内容调整为暖纸底、石墨灰、hachure、高 roughness 的铅笔草图风。
- 工具区卡片同步显示 `v1.0.1` 与本次更新日期，布局审计改为校验画板、临时互传和日语工具三张真实卡片。
- 建立独立版本、项目清单、AGENT/AGENTS、更新日志和文档联动门禁。

## 1.0.0 - 2026-07-30

- 初次提供公共房、密码房、Excalidraw + Yjs 实时协作、匿名身份、图片、导出、Durable Object 持久化与私有 R2 资源。
- 公共房不设空房 TTL；密码房最后离开 24 小时后自动清理。
