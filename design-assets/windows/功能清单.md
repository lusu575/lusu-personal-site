# lusu575.com 现站功能清单（公开功能）

盘点时间：2026-11-21。依据：GitHub 仓库 main 分支源码（index.html、js/routes、js/data、games/catalog.json、PROJECT_CONTEXT.md）与线上首页文本。
原则（鲁肃 2026-11-21 定）：**布局可以调整，功能不能少。** 本清单是重构效果图与实现的功能底线。

## 路由总览（8 个）
home（桌面）、knowledge（知识库）、blog（博客/杂谈）、videos（视频）、resources（工具/资源）、games（游戏）、chatroom（聊天室）、about（关于）。全站三语：中文 / English / 日本語。

## 1. 知识库 knowledge
- 文章列表：按**分类**筛选（分类带计数）、**标签**（三语标签名去重）、**置顶**文章优先。
- **搜索**：多词 AND、NFKC 归一、三语标签匹配，按摘要批次扫描。
- 分页：默认 12 条/页，「加载更多」，切换分类/搜索保留各自滚动与请求上下文。
- **文章阅读页**：正文、**目录（TOC）**、顶部**阅读进度条**（百分比）、**摘要展开/收起**、作者与语言替代元信息；文章链接保留新标签打开行为。
- 每日 AI 新闻是其中一个分类（daily-ai-news），有独立 RSS（见关于页）。

## 2. 博客/杂谈 blog —— 已下线，不进新版
- 现站为桌面端可选栏目（手机端早已下线），短文流，内容走接口。
- **鲁肃 2026-11-21 明确：杂谈区下线，新版不要。** 效果图与实现都不包含，本清单后续条目与之无关。

## 3. 视频 videos
- 视频卡片列表，按**分类**组织；卡片 = 渐变封面 + 标题 + 简介（均三语）。
- 卡片标注**平台**（Bilibili / YouTube），点击**外链跳转**到平台播放，站内没有自建播放器。
- 手机端为完整 16:9 大封面、标题简介在下方、作者日期与播放操作并排。

## 4. 工具/资源 resources
工具卡（每卡含图标、名称、三语说明、版本/更新日期、标签、用户用途与技术详情分开）：
- **在线画板**（公开）：无需登录；公共画板 + **密码房**实时协作；最后参与者退出后 24 小时删除；可导出完整图片；授权 Agent 可读写场景。
- **临时互传 Quick Transfer**（公开）：手机与电脑间传文字、图片、文件；**登录后**用同一口令进房间；内容保留 **24 小时**；房间过期/删除即物理删除不备份；草稿仅房间内存存在。
- **日语的言外之意**（公开）：日语学习工具（tools/japanese-subtext）。
- 资源下载条目：示例工具包、VRChat 素材包、本地模型配置模板等。
- **在线 ComfyUI · MiniMax H3**：站长专用，公开工具区**隐藏**（showInTools: false），走 /admin 入口——非公开功能，效果图不画。

## 5. 游戏 games
五个独立游戏，共用全屏 shell，全部接入**本站语言启动**与**云存档**：
- 猫国建设者（Kittens Game）、小黑屋（A Dark Room）、2048、Hextris、人生重开模拟器。
- 云存档：登录后自动同步（每 10 分钟）+「立即同步」手动 + 切出页面补同步；游戏内有存档/云端/许可证/AI 面板（小屏默认收起）。
- 每个游戏有封面、简介（三语）、语言支持标注、许可证信息。

## 6. 聊天室 chatroom
- 身份：可设置/修改**昵称**（匿名身份）。
- **普通房间（大厅）**：每 5 秒自动刷新；**密码房**：双方输入相同密码进入同一房间，带「？」说明浮层；密码房最后一条消息超过 **24 小时**自动清理，后台可删。
- 发送规则：单条上限 **300 字**（带字数计数），**每 3 秒**可发一条；自动滚动开关；未读提醒按钮；同步状态显示；发送失败可重试。

## 7. 关于 about
- 头像、昵称（鲁肃）、兴趣（AI / 游戏 / 工具折腾）、联系方式、网站状态（持续建设中）、自我介绍。
- 社交链接区（独立一排）。
- **每日 AI 新闻 RSS 入口**：独立放在介绍文字下方（不与社交账号混排），文案随三语切换；RSS 只含 daily-ai-news 最近 50 期。

## 8. 全站级功能
- **账号系统**：注册 / 登录 / 退出（会话 Cookie）；互传、游戏云存档依赖登录；聊天室与画板可用匿名身份。
- **语言切换**：中 / 英 / 日三语，全站文案与内容随之切换。
- **欢迎窗**：默认不自动弹；桌面「最近更新」入口 / 移动首页欢迎入口主动打开（welcome=1 预览）；内容为最近 5 条网站更新摘要。
- **首页动态壁纸**：桌面按时段（morning/day/dusk/night）视频壁纸 + 静态底图兜底，手机/low/Save-Data/减动效时零视频请求（新版已改为四季池塘，此条为现站行为记录）。
- 移动端：底部六入口 Dock（可横滑、可收起）、手机 OS 式主屏。
- 连接状态指示（connection-status）与 monitor 图标用于状态类 UI。
