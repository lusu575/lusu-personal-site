- 复审日期：2026-07-11

- 内容量：1,020 句对话、258 道题（219 道单选、39 道多选）
- 目标难度：Level 1 = N3，Level 2 = N2，Level 3 = N1
- 结论：通过。所有发现的问题已直接修入题库，没有改变关卡数、台词数、题目数、正确答案位置、稳定 ID 或 `audioId`。

## 复审方法

逐关检查标题、场景、人物、台词、题干、选项、正确答案、证据行与五类解释，并从三个角度交叉复核：

1. 日语教学：语法、自然度、读音、JLPT 难度、三语语义对应。
2. 语用推理：潜台词是否能由当前场景与证据推出、正确项是否唯一、是否存在越界推断或刻板印象。
3. 游戏写作：题材与节奏、干扰项可信度、答案位置保持、正确项长度偏差、前后关重复。

另执行蓝图、结构、读音、分词覆盖、重复文本、插图资源与选项长度的自动审计。

## 主要修订

### 日语、事实与逻辑

- 修正 Level 1 中战斗指令、陪护机器人用词、世纪换算等不自然或事实错误内容。
- 修正 Level 2 中咖啡因与睡眠的推断、姓名用词、既读场景视角、清扫后遗留物、失物招领隐私、报销拆单、汉字书写部位、深夜播放时间及杯数等逻辑。
- 修正 Level 3 中航行日志、通知既读时间、欠税范围、票据收纳、顾客台词、抄袭指控撤回、坐标名称、时间顺序及旋转居住环“向下”方向等问题。
- 对 Level 3 后段的数字、日期、专名与字母读法做专项校正；`readingJa` 与 token `reading` 均只保留可直接朗读的假名。

### 潜台词、证据与解释

- 重写证据不足或存在另一合理答案的题目，使正确项能由指定证据行唯一推出。
- 将失物招领改为先隐藏颜色与名称、由认领者提供特征验证，避免诱导错误认领。
- 将抄袭争议改为原指控者主动撤回误判并道歉，修复人物责任与管理员删帖逻辑。
- 为 Level 3 前 20 关中误复用上一题的解释补写题目专属 `literal`、`intent`、`evidence`、`nuance`、`alternative`，并同步日/中/英三语。
- 重写 Level 3 最后三关的模板化解释，使每题都引用本关具体线索。

### 游戏性与答案偏差

- 重写过短、过弱或一眼可排除的干扰项，保持其语法自然且与场景有关；三语与选项 TTS 文本同步更新。
- 单选题“正确项是唯一最长选项”的比例：

  | 范围 | 唯一最长 / 单选题 | 比例 |

  | Level 2 | 21 / 60 | 35.0% |

  另有 27 题为并列最长，不计入“唯一最长”。三个等级均不超过 60%。
- `L2-019` 调整为全男声关卡：三名角色分别使用 `male-casual`、`male-calm`、`male-serious`，选项旁白使用 `male-serious`。

### 插图

- 插图风格仅使用 `none`、`crayon`、`chibi-four-panel`；题库中不存在黑白、线稿、单色等描述。
- 19 个启用插图的关卡均有对应资源，缺失数为 0。
