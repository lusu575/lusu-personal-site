# Desktop Shell Overrides

- Keep the top Pixel Glass HUD and bottom XP taskbar fixed to the viewport.
- Active windows use a clearer titlebar highlight and edge depth; inactive/background layers visually recede without losing contrast.
- Desktop icons remain single-click buttons with selected, pressed, opening, returning, and focus-visible states.
- Window transitions use 320–440ms spatial motion; routine control feedback stays 90–260ms.
- Account popover must overflow the top bar and remain above every main window.
- Optional drag behavior is omitted unless it can be bounded, pointer-fine only, nonpersistent, and regression-safe.
