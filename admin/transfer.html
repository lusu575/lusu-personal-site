    费用与报警

    站内数据是估算；正式账单以 Cloudflare 为准。

    写入类操作（Class A）包括上传、分片初始化与完成；读取类操作（Class B）包括下载和对象读取。存储量按本月累计 GB·月估算，容量显示使用 MiB / GiB；两者单位不同。

    配置费用通知与了解统计口径
    1. 在 Cloudflare 账户的账单 / 用量页面配置官方 1、3、5 美元预算提醒。本站无法读取官方提醒是否启用，请在 Cloudflare 核对。
    2. 需要站内通知时，在 Pages 项目的 Production 环境中配置 Secret TRANSFER_ALERT_WEBHOOK_URL，指向你已有的通知接收服务。
    3. 如接收服务支持邮件转发，可再配置 TRANSFER_ALERT_EMAIL。只填邮箱不会发送邮件；邮件由接收服务转发。
    4. 保存环境变量后重新部署，再回来刷新数据。确认接收服务就绪后，可手动发送一次测试通知，查看下方记录并在接收端核对。

    站内费用只覆盖本功能记录的 R2 存储与操作估算，不能代表整个 Cloudflare 账户账单。环境变量 TRANSFER_ALERT_THRESHOLDS 若已设置，将优先于本页报警阈值。
