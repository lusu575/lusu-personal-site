# 鲁肃个人站管理后台专用 CHANGELOG

> 管理后台专用说明：本文档只记录 `/admin/` 管理后台的私有维护记录，不等同于主站根目录 `CHANGELOG.md`。后台私有更新不写入主站知识库 `site-updates`，也不展示到首页最近更新。

## 2026-06-16

- 视频分类与 Bilibili 元数据维护修复：
  - 默认视频分类 seed 改为只插入缺失分类，不再覆盖后台维护过的 slug、中文名、英文名、日文名、排序和启用状态，避免冷启动或 schema guard 后把分类名还原。
  - 后台保存已有视频时，如果视频 URL 没有变化，不再重复抓取 YouTube / Bilibili 外部元数据，减少 Bilibili 风控或 HTTP 412 对普通编辑保存的影响。
  - Bilibili 元数据抓取补强请求头、详情接口、移动页、`__NEXT_DATA__`、页面标题和 meta 兜底；抓取失败时保留可读错误，并提示管理员手动补全标题、作者和封面。
  - 后台新增重复视频拦截，避免同一平台同一视频 ID 被重复录入。
  - 视频分类勾选区标识停用分类，新视频不能继续选择未关联的停用分类；已关联的停用分类仍保留显示，方便管理员移除。
  - 同步更新 `adminUpdates`、后台 CSS/JS query、后台维护规则和项目变更记录。

## 2026-06-15

- 账号管理和统计口径优化：
  - 后台新增“账号管理”标签页，位置在“后台更新记录”上方。
  - 账号页可查看所有注册账号的邮箱、角色、密码加密状态、最近登录、活跃会话、云存档数量、登录履历和近期站内活跃。
  - 密码不展示明文，也不把 `password_hash` 返回给前端；后台只提供设置新密码的能力，保存后会清空输入框。
  - 新增 `user_login_events` 表记录成功登录/注册后的登录履历，只保存掩码 IP 前缀、IP hash、地区、设备摘要和时间，不保存完整明文 IP。
  - 访问统计改为登录账号优先识别：已登录用户按账号合并为同一个不可逆统计 ID，同一账号多设备、多次访问仍只计为 1 个 UV；匿名访客继续使用隐藏访客 cookie。
  - 实时大屏新增自然语言说明，解释 PV、UV、在线访客和点击数据的含义，减少只看缩写造成的误读。
- 视频排序和 Bilibili 元数据兜底修复：
  - 后台视频列表和公开视频列表统一为置顶优先，未置顶视频按排序值从大到小显示。
  - 后台新建视频默认填入当前最大排序 +10，视频分类新建也使用同样的默认追加逻辑。
  - 默认视频分类 seed 不再覆盖后台维护过的排序和启用状态，避免冷启动后分类排序被还原。
  - Bilibili 元数据抓取在 API 412 后继续尝试页面 meta、结构化数据和更宽的页面状态解析，减少标题、作者、发布时间、简介和封面缺失。
  - 后台视频列表增加排序值提示，便于确认前台展示顺序。

- 视频元数据和后台更新记录优化：
  - 后台视频预览改为限制宽度的小播放器，避免 YouTube / Bilibili iframe 在编辑区占满整页。
  - YouTube 元数据抓取在 oEmbed 基础上补充页面元信息解析，尽量自动填入简介和发布时间。
  - Bilibili 元数据抓取增加浏览器化请求头、页面 `__INITIAL_STATE__` 备用解析和 b23 短链跟随兜底，降低 HTTP 412 或跳转异常导致的解析失败。
  - 外部元数据简介改为安全截断，避免长简介导致整次抓取失败。
  - 新增独立“后台更新记录”标签页，后台导航顺序调整为实时大屏、访问来源、点击埋点、知识库文章、视频管理、视频分类管理、聊天室管理、后台更新记录、后台说明。
  - `admin/docs/ADMIN_SKILL.md` 新增硬性规则：每次后台更新后必须同步维护后台页面内 `adminUpdates` 和本文档。

- 新增后台专用文档包：
  - 新增 `admin/docs/ADMIN_PROJECT_CONTEXT.md`，作为 `/admin/` 管理后台专用上下文。
  - 新增 `admin/docs/ADMIN_SKILL.md`，沉淀后台权限、隐私、视频、文章、聊天室和缓存维护规则。
  - 新增 `admin/docs/ADMIN_CHANGELOG.md`，将后台私有更新记录从主站公开更新体系中进一步区分出来。
  - 明确后台专用文档不等同于主站 `PROJECT_CONTEXT.md`、根目录 `CHANGELOG.md` 或主站项目 Skill。

- 视频管理系统：
  - 后台新增“视频管理”和“视频分类管理”模块。
  - 支持输入 YouTube / Bilibili / b23.tv 链接，由服务端识别平台、生成规范化 `embed_url` 并抓取标题、简介、作者和封面。
  - 支持视频草稿、发布、隐藏、排序、置顶、删除、刷新元数据和分类关联。
  - 支持视频分类新增、编辑、停用、排序和删除；“全部”分类继续只由前台生成，不写入数据库。

- 后台视觉优化第一版：
  - 统一侧边栏、顶部栏、XP 面板、按钮、表格、状态标签、空状态和提示信息。
  - 改善实时大屏、文章管理、访问来源、点击埋点和聊天室管理在桌面、平板、移动端的阅读布局。
  - 修正移动端侧边栏高度和编辑区滚动边界。
  - 后台更新记录继续独立于主站知识库 `site-updates`。

- 文章访问 PV/UV 统计：
  - 公开文章详情接口成功返回文章时写入 `article_view_events`。
  - 后台实时大屏新增热门文章表，展示文章标题、slug、PV、UV 和最近访问时间。
  - 后台文章列表和文章编辑详情新增每篇文章总 PV/UV 与今日 PV/UV。

- 管理后台 MVP 接入：
  - 新增独立 `/admin/` 中文管理后台。
  - 新增实时监控大屏、知识库文章管理、访问来源、点击埋点、聊天室管理、后台项目介绍和私有后台更新记录。
  - 新增 `functions/admin/_middleware.js`，后台静态资源复用主站 `lusu_session` 并校验 `users.role = admin`。
  - 所有 `/api/admin/*` 接口继续使用服务端 admin 权限校验。
  - 聊天室后台支持消息编辑、隐藏/恢复、删除，并按隐藏 visitor id 或 IP hash 禁言。
